# Dr. Prabhakar Bhandari — Academic & Research Portfolio

A responsive, single-page academic portfolio for Dr. Prabhakar Bhandari, focused on Mechanical Engineering, thermal research, publications, teaching, and research-support responsibilities (RDC/CIF).

## Files
- `index.html` — complete website; no build tools or dependencies required.
- `README.md` — setup and publishing instructions.

## Preview on your computer
1. Download and extract the ZIP.
2. Double-click `index.html` to open it in your browser.

## Publish free with GitHub Pages
1. Sign in to GitHub and create a **public** repository, for example `prabhakar-bhandari-portfolio`.
2. Upload `index.html` and `README.md` to the repository's root folder.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then click **Save**.
6. Wait for the deployment to finish. The Pages screen will show the website URL.

The URL will typically look like `https://YOUR-USERNAME.github.io/prabhakar-bhandari-portfolio/`. The exact address depends on your GitHub username and repository name.

## Personalise before publishing
Search in `index.html` for the following placeholders and replace them:
- `YOUR_EMAIL@example.com` — professional email address
- `YOUR_GOOGLE_SCHOLAR_URL` — Google Scholar profile
- `YOUR_ORCID_URL` — ORCID profile
- `YOUR_SCOPUS_URL` — Scopus author profile
- `YOUR_LINKEDIN_URL` — LinkedIn profile

You can also replace the `PB` monogram with a professional photograph, add a downloadable CV, and add DOI/publisher links to the publication entries. Verify publication metadata and all dates before publishing.
